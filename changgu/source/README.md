# 연구진흥과 창구 — 소스 코드

부산대학교 연구처 연구진흥과가 실제로 쓰는 「창구」 화면의 소스입니다.
회의비 한도 같은 규정을 물으면 공개 지침에서 금액·근거·필요한 서류를 찾아 주고, 회의비 서류(기안 공문 본문·원인행위 입력표·회의록 문구)까지 만들어 줍니다.

- 공개판 주소: https://aimaestroresearch.github.io/pnu-agents-demo/changgu/
- 로그인·설치·서버 없이 **파일 하나(index.html)** 로 동작합니다. 적은 말은 어디에도 저장·전송되지 않습니다.
- 코드는 직접 쓰지 않았습니다. 무엇이 필요한지 AI에게 말로 설명해 만들었습니다.

---

## 1. 그냥 써 보기 (1분)

`index.html` 을 더블클릭하면 끝입니다. 인터넷이 끊겨도 같은 모습으로 열립니다.

## 2. 우리 부서 규정으로 바꾸기 (30분)

고칠 파일은 **`시연본/index.src.html` 하나**입니다.

1. 파일을 메모장(또는 아무 편집기)으로 엽니다.
2. `const RULES_DB = [` 를 찾습니다. 규정 하나가 `{ title: …, keys: […], lines: […], basis: …, note: … }` 한 덩어리입니다.
   - `title` = 화면에 뜨는 제목 (예: 회의비 · 간담회비)
   - `keys` = 이런 낱말이 들어간 질문이면 이 규정을 보여 줍니다 (예: 회의비, 간담회, 식대)
   - `lines` = 표의 줄 `['항목', '내용']`
   - `basis` = 근거 규정 이름과 개정일 · `note` = 주의 한 줄
3. 우리 부서 규정으로 숫자와 근거를 바꾸고 저장합니다. **숫자는 반드시 현행 원문과 한 줄씩 대조하세요.**
4. 회의비 서류 기능의 기준(1인 한도, 22시, 주말·공휴일 등)은 같은 파일의 `const MEET` 에 있습니다.
5. 아래 3번으로 다시 만듭니다.

## 3. 다시 만들기 (파이썬)

```
cd 시연본
python build.py --public     # → 공개판/index.html  (이 저장소의 공개판과 같은 모양)
python build.py              # → 시연본/index.html  (발표 시연용: 시연 띠·QR 칸)
python build.py --deploy     # → 운영판/index.html  (구글 Apps Script 웹 앱용, 아래 4번)
```

- 필요한 것: 파이썬 3, `pip install fonttools brotli`
- 글꼴: Pretendard(무료, SIL Open Font License)를 받아 `시연본/fonts/PretendardVariable.woff2` 로 두면 같은 모양이 됩니다. 없으면 기기 기본 글꼴로 만들어집니다.
- 빌드는 화면에 쓰인 글자만 골라 글꼴과 그림을 파일 안에 심습니다. 그래서 결과가 파일 하나입니다.

## 4. 실제 도구 버튼 · 사용 횟수 세기 (선택, 구글 Apps Script)

`운영판/` 은 같은 화면을 학교 구글 계정의 무료 웹 앱으로 올리는 판입니다. 서버는 **화면 내려 주기와 익명 사용 횟수 세기** 두 가지만 합니다(적은 말은 받지 않음).

1. `운영판/links.json` 에 출구마다 우리 도구 주소를 적습니다(비우면 버튼이 안 생김). 누구나 열 수 있는 주소만 넣으세요.
2. `python build.py --deploy` 로 `운영판/index.html` 을 만듭니다.
3. script.google.com → 새 프로젝트 → `Code.gs` 붙여 넣기, HTML 파일 `index` 를 만들어 `index.html` 붙여 넣기, 프로젝트 설정에서 `appsscript.json` 표시 후 덮어쓰기.
4. 배포 → 새 배포 → 웹 앱 → 실행 계정 「나」, 액세스 「모든 사용자」 → 나온 주소가 우리 부서 창구입니다.

## 5. 규정봇(출구 1)은 따로 만듭니다

창구의 규정 답은 위 `RULES_DB` 에 적은 것만 나옵니다. 규정 원문 전체에 질문하고 싶으면, 구글 계정에서 무료로 쓰는 **노트북형 AI 도구**(자료를 올려 두면 그 자료로만 답하는 도구)에 **공개된 규정 원문만** 올려 「규정봇」을 만들고, 그 주소를 `links.json` 의 `rule` 에 넣으면 됩니다.
- 회의록·영수증·명단 같은 개별 사안 자료는 올리지 않습니다. 질문은 말로만 합니다.
- 금액은 개정이 잦습니다. 옛 판 자료가 섞이면 옛 숫자로 답하니 현행본만 올리세요.

## 쓰실 때 알아 두실 것

- **코드는 가져다 고쳐 쓰셔도 됩니다.** 출처(부산대학교 연구처 연구진흥과 창구)를 남겨 주시면 고맙겠습니다.
- **부산대학교 상징(`시연본/자산/부산대_상징.webp`)과 산지니 그림(`시연본/자산/산지니_*.webp`)은 부산대학교의 것입니다.** 다른 기관에서 쓰실 때는 빼거나 우리 기관 그림으로 바꿔 주세요(같은 이름의 파일로 바꾸면 됩니다).
- 실린 규정 숫자는 2026년 10월 기준 부산대학교 공개 지침입니다. 안내일 뿐이고, 판단·승인은 담당자와 결재선이 합니다.
- 글꼴 Pretendard 는 SIL Open Font License 1.1 입니다.
