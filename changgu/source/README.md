# 연구진흥과 창구 — 소스 코드

부산대학교 연구처 연구진흥과가 실제로 쓰는 「창구」 화면의 소스입니다.
회의비 한도 같은 규정을 물으면 공개 지침에서 금액·근거·필요한 서류를 찾아 주고, 회의비 서류(기안 공문 본문·원인행위 입력표·회의록 문구)까지 만들어 줍니다.

- 공개판 주소: https://aimaestroresearch.github.io/pnu-agents-demo/changgu/
- 화면은 로그인·설치 없이 **파일 하나(index.html)** 로 열립니다. 공개판은 **새 규정 질문과 공고 목록만** 창구 서버(학교 계정의 무료 구글 Apps Script)에 묻습니다 — 적은 질문은 답을 만들 때만 보내고 저장하지 않으며, 서버는 횟수만 셉니다. 회의비 서류 칸에 적은 글자는 보내지 않습니다.
- 규정 답은 **AI가 공개 규정 28종에서 관련 조항을 찾아 근거 번호를 붙여 직접 답합니다**(무료 키, 하루 횟수 한도). 자료에 없으면 지어내지 않고 「없다 + 이런 규정이 필요하다」고 답합니다.
- 코드는 직접 쓰지 않았습니다. 무엇이 필요한지 AI에게 말로 설명해 만들었습니다.

---

## 1. 그냥 써 보기 (1분)

`index.html` 을 더블클릭하면 끝입니다. 인터넷이 끊겨도 같은 모습으로 열리고(질문 버튼의 실제 규정봇 기록·회의비 서류는 그대로 됨), 새 질문의 AI 답과 실시간 공고는 인터넷이 될 때 나옵니다.

## 2. 우리 부서 규정으로 바꾸기 (30분)

고칠 파일은 **`시연본/index.src.html` 하나**입니다.

1. 파일을 메모장(또는 아무 편집기)으로 엽니다.
2. `const RULES_DB = [` 를 찾습니다. 규정 하나가 `{ title: …, keys: […], lines: […], basis: …, note: … }` 한 덩어리입니다.
   - `title` = 화면에 뜨는 제목 (예: 회의비 · 간담회비)
   - `keys` = 이런 낱말이 들어간 질문이면 이 규정을 보여 줍니다 (예: 회의비, 간담회, 식대)
   - `lines` = 표의 줄 `['항목', '내용']`
   - `basis` = 근거 규정 이름과 개정일 · `note` = 주의 한 줄
3. 우리 부서 규정으로 숫자와 근거를 바꾸고 저장합니다. **숫자는 반드시 현행 원문과 한 줄씩 대조하세요.**
4. 회의비 서류 기능의 기준(1인 한도, 22시, 주말·공휴일 등)은 같은 파일의 `const MEET` 에 있습니다.
5. 아래 3번으로 다시 만듭니다.

## 3. 다시 만들기 (파이썬)

```
cd 시연본
python build.py --public     # → 공개판/index.html  (이 저장소의 공개판과 같은 모양)
python build.py              # → 시연본/index.html  (발표 시연용: 시연 띠·QR 칸)
python build.py --deploy     # → 운영판/index.html  (구글 Apps Script 웹 앱용, 아래 4번)
```

- 필요한 것: 파이썬 3, `pip install fonttools brotli`
- 글꼴: Pretendard(무료, SIL Open Font License)를 받아 `시연본/fonts/PretendardVariable.woff2` 로 두면 같은 모양이 됩니다. 없으면 기기 기본 글꼴로 만들어집니다.
- 빌드는 화면에 쓰인 글자만 골라 글꼴과 그림을 파일 안에 심습니다. 그래서 결과가 파일 하나입니다.

## 4. 실제 도구 버튼 · 사용 횟수 세기 (선택, 구글 Apps Script)

`운영판/` 은 같은 화면을 학교 구글 계정의 무료 웹 앱으로 올리는 판입니다. 서버는 **화면 내려 주기와 익명 사용 횟수 세기** 두 가지만 합니다(적은 말은 받지 않음).

1. `운영판/links.json` 에 출구마다 우리 도구 주소를 적습니다(비우면 버튼이 안 생김). 누구나 열 수 있는 주소만 넣으세요.
2. `python build.py --deploy` 로 `운영판/index.html` 을 만듭니다.
3. script.google.com → 새 프로젝트 → `Code.gs` 붙여 넣기, HTML 파일 `index` 를 만들어 `index.html` 붙여 넣기, 프로젝트 설정에서 `appsscript.json` 표시 후 덮어쓰기.
4. 배포 → 새 배포 → 웹 앱 → 실행 계정 「나」, 액세스 「모든 사용자」 → 나온 주소가 우리 부서 창구입니다.

## 5. AI 작동판 — AI가 공개 규정으로 직접 답하게 (무료 키, 1시간)

`실제판/` 은 창구 서버입니다. 질문이 오면 ① 공개 규정 조각에서 관련 조항을 찾고(낱말 점수) ② 무료 AI 키로 근거 번호를 붙여 짧게 답합니다. 깊은 추론이 필요 없는 일이라 **가벼운 무료 모델**로 충분합니다.

1. 우리 규정 글자(txt)를 `실제판/_규정본문/` 에 넣고 `python 실제판/make_rg_data.py` → `rg_data_*.html`·`rg_docs.html` 이 생깁니다. **현행본만** 넣으세요(옛 판이 섞이면 옛 숫자로 답합니다). 표는 「등급별 한 줄」로 풀어 쓰면 더 정확합니다.
2. script.google.com 새 프로젝트에 `Code.gs`·`Rg.gs`·`appsscript.json`·`rg_*.html` 을 올립니다(`clasp push` 를 쓰면 `.claspignore` 대로 필요한 것만 올라갑니다). 화면 `index.html` 은 `python 시연본/build.py --live` 로 만듭니다.
3. **AI 스튜디오에서 키를 만들어**(결제를 연결하지 않은 무료 등급 프로젝트) 프로젝트 설정 → 스크립트 속성 `GEMINI_API_KEY` 에 넣습니다. 키는 코드에 쓰지 않습니다.
4. 선택: `LIVE_PASSWORD`(비번 화면, 바꾸면 바로 반영) · 한도 `RG_DAY_MAX`·`RG_USER_MAX`(누구나 몫) · `RG_LIVE_DAY_MAX`·`RG_LIVE_USER_MAX`(비번 몫).
5. 배포 → 웹 앱(실행 계정 「나」, 액세스 「모든 사용자」). 그 주소를 `실제판/배포URL_날짜.txt` 에 적고 `python 시연본/build.py --public` 하면 공개판이 그 서버에 묻습니다.

**비용 0원 조건**: 키를 만든 프로젝트에 결제를 연결하지 않기. 무료 한도를 넘으면 구글이 거절할 뿐 청구되지 않고, 창구는 AI 없이 조항 원문만 보여 줍니다. **더 많이·더 정확하게** 쓰려면 결제를 연결한 키(유료 API)나 기관 구독으로 한도와 모델을 늘릴 수 있습니다 — 쓴 만큼 요금이니 기관 예산·보안 절차를 먼저 확인하세요.

## 6. 규정봇 — 저희가 실제로 만든 방법 (코드 없음, 30분)

창구의 질문 버튼에 나오는 답은 실제 규정봇에 물어본 기록입니다. 규정봇(노트북)은 이렇게 만들었습니다.

1. 구글 계정으로 **제미나이 노트북**(notebook.google.com)을 열고 새 노트북을 만듭니다.
2. **공개된 규정·지침만** 소스로 올립니다. 저희는 30종 — 공무원 여비 규정·청탁금지법 같은 법령, 학교 회계·연구비 규정, 사업비 집행 지침, 연구비 사례집, 개정된 금액을 모은 현행 요약 한 장.
3. 메모에 지침 한 줄을 적어 소스로 넣습니다. 저희 문장: **「규정에 근거해서 답해주고 출처는 항상 표기해줘」**
4. 시험합니다 — 자주 오는 질문 몇 개 + **넣지 않은 질문 하나**(「없다」고 답하는지) + **개정된 금액 하나**(새 금액으로 답하는지).
5. 부서원에게만 공유합니다(뷰어). 그 주소를 `운영판/links.json` 의 `rule` 에 넣으면 창구 출구 1 버튼이 됩니다.

**개인정보 보호의 핵심은 「공개된 규정만 넣는다」입니다.** 회의록·영수증·명단·내부 검토 문서는 넣지 않고, 질문도 이름·연락처 없이 말로만 합니다. 처음부터 넣지 않으면 새어 나갈 것이 없습니다.
- 같은 규정의 옛 판이 섞이면 옛 숫자로 답합니다(저희도 한 번 3만 원으로 틀렸습니다). 현행본만 넣고, 개정되면 옛 판은 지웁니다.
- 답은 참고용입니다. 판단·승인은 담당자와 결재선이 합니다.
